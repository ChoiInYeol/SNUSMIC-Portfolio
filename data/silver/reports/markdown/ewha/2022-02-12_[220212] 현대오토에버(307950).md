| 커넥티드 카 Value Chain |  |  | 미래차 경쟁력 확보의 일환으로 차량의 디지털화가 진행되며 차량용 소프트웨어(SW)를 이용하는 커넥티드카가 성장할 전망이다. 커넥티드 카는 무선통신을 기반으로 한 네트워크 연결을 통해 차량과 주변 사물들이 서로 소통하며 탑승자에게 각종 서비스를 제공한다.<br>커넥티드 카 Value Chain은 전자 제어 유닛(ECU), 차량용 단말기, 플랫폼 및 차량용 SW,<br>완성차 업체로 구성되며, 플랫폼 및 차량용 SW 업체는 차량용 단말기 내 다량의 전자 제어<br>유닛들의 데이터를 통합 제어하는 SW를 구축해 완성차 업체에 공급한다. 차량의 디지털화가 진행됨에 따라 차량 내 데이터 증가로 데이터를 통합 제어하는 SW의 중요성은 커질 전망이다. 향후 커넥티드 카 등 차세대 자동차 시장의 성장과 함께 커넥티드 카 Value Chain<br>내 차량용 SW 및 SW 플랫폼 납품을 맡는 업체들의 수혜를 예상한다. |

| 커넥티드 카 플랫폼 및<br>차량용 SW 플랫폼 개요 |  |  | 커넥티드 카 시장 성장과 함께 탑승자를 위한 차세대 자동차 서비스 시장이 커짐에 따라 향후 차량용 SW의 성장을 전망한다. 완성차 업체들은 탑승자에게 각종 자동차 서비스를 제공하기 위해 커넥티드 카의 HW에 다양한 원격 기능 및 편의 기능을 포함한 차량용 SW를 탑재하는 추세이다. 차량용 SW는 자동차 서비스의 증가에 따라 SW 플랫폼 형식으로 발전하고 있다.<br>커넥티드 카 내 원격 기능 및 편의 기능의 탑재는 각 기능을 담당하는 전자 제어 유닛(ECU)의 개수와 전자 제어 유닛을 제어하는 통합 제어 장치(DCU)의 개수를 증가시켰다. 이에 따라 각 유닛과 장치가 전송하는 데이터 양도 증가했다. 데이터 양이 증가할수록 차량 내 데이터 과부하 및 혼선이 일어날 수 있으므로 차량 내 데이터 관리가 필요하다. 따라서 차내 다량의 데이터 관리를 위해 차 내 전장 제어기는 유닛만 따로 존재하던 분산형에서, 유닛과 통합 제어 장치를 모아서 통제하는 통합 제어기 형태로 발전하고 있다. 전장 제어기의 형태가<br>발전하면서 제어기 내 데이터 관리를 담당하는 차량용 SW 플랫폼 구축이 필요해졌다. 현재<br>테슬라, 엔비디아 등 차량용 SW를 개발하는 업체에서 차량용 SW 플랫폼을 지속적으로 개발하여 완성차에 탑재, 제공하는 추세이다. |  |  |
