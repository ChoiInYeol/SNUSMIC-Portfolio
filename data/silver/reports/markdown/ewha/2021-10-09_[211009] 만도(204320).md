| AV(자율주행차) 시장 개요 |  | 글로벌 AV시장은 CAGR 22.77%로 성장하여 20년 210억 달러에서 26F 720억 달러에 달할 것으로 전망한다. AV에 필수 탑재되는 자율주행 시스템은 LV0-5로 총 6단계로 구성되어 있으며, 크게 주행 주체가 사람인 LV0-2와 주행 주체가 기계인 LV3-5로 나뉜다.<br>ADAS(Advanced Driver Assistance System)는 보통 LV2-4 시스템을 지칭하며, 현재 상용화된 단계는 LV1, 2, 아이오닉 5를 기점으로 확대되기 시작한 ADAS는 LV2.5-4이다. |  |  |

| ADAS 기능 및<br>시스템 구성 |  |  | ADAS는 각종 센서를 통해 정보를 수집하고 종합 판단을 내려 제어하는 방식으로 작동한다.<br>작동 방식은 크게 인지, 판단, 제어로 나뉘며, 카메라, 레이더, 라이더 등의 센서를 통해 주행<br>환경을 탐색(인지 단계)하고, ECU, DCU 등으로 종합적인 판단을 내리며(판단 단계) 차량의<br>주행을 제한(제어 단계)한다. 인지 단계에 사용되는 센서는 초음파, 라이다, 카메라, 레이더<br>등이며, 이는 각 ADAS 시장 내에서 5%, 11%, 37%, 47%를 차지한다. 이렇게 취득한 정보를<br>종합적으로 판단하는 제어 단계에서 현재는 ECU가 상용화되고 있지만 레벨이 상승함에 따라 전력 효율성 등을 위해 DCU가 더욱 확대될 예정이다. |
