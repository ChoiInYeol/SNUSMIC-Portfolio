| 반도체 테스트 산업 개요 |  | 반도체 테스트 산업은 종합 반도체 제조사나 팹리스 업체 등에서 웨이퍼나 반도체 칩을<br>제공받아 테스트하는 서비스업이다. 또한 고가의 테스트 장비에 대한 투자가 선행되어야 하며 기존에 검증된 업체를 선호하는 경향이 있어 진입장벽이 높은 산업이다. 반도체<br>테스트는 웨이퍼에 형성된 IC의 전기적 동작여부를 테스트해 불량품을 선별하는 웨이퍼<br>테스트와, 패키징을 거친 IC의 전기적 동작여부를 최종적으로 테스트하는 패키지 테스트로 나뉜다. 이때 데이터 처리량이 높을수록 테스트 속도가 향상되기 때문에 반도체 테스트 업체는 데이터 처리량이 높은 장비를 보유하는 것이 중요하다. |

| 시스템 반도체 테스트 시장 |  | 반도체 테스트 시장은 메모리 반도체 테스트 시장과 시스템 반도체 테스트 시장으로 나뉜다. 메모리 반도체가 소품종 대량생산인 반면, 시스템 반도체는 다품종 소량생산이기<br>때문에 시스템 반도체 테스트 장비는 메모리 반도체 테스트 장비에 비해 세분화돼있다.<br>따라서 시스템 반도체 테스트의 경우 메모리 반도체 테스트보다 외주 비중이 더 높다.<br>이때 시스템 반도체 테스트를 수행하는 시스템 반도체 OSAT 업체의 평균 OPM은<br>2020년 기준 16.6%로, 메모리 반도체 OSAT 업체에 비해 11.4%p 높아 반도체 시장 성장에 따라 더 큰 수혜를 전망한다. 이에 더해 글로벌 시스템 반도체 시장은 2020년<br>2,310억 달러에서 2026F 3,309억 달러로 CAGR 6.2% 성장할 것을 전망한다. 시스템 반도체 특성상 테스트의 대부분이 외주에 의존한다는 점에서, 글로벌 시스템 반도체 시장의 성장이 글로벌 시스템 반도체 테스트 시장의 성장으로 이어질 것을 전망한다. |
