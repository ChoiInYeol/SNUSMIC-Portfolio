| 반도체 패키징 산업의 개요 |  |  | 기존에는 반도체 미세화를 통해 성능 개선을 추구했지만 미세화 기술이 한계에 다다르면서<br>성능 개선을 위한 대안으로 패키징 기술의 중요성이 부각되고 있다. 이는 패키징 기술을 통해 반도체의 집적도를 높임으로써 전기신호 전달 속도를 향상시킬 수 있기 때문이다. 반도체 제조공정은 크게 전공정과 후공정으로 나뉘며 반도체 패키징은 이중 후공정에 해당한다.<br>반도체 패키징은 반도체 제조공정 중에서도 반도체의 모듈, 기판, 칩 간의 연결 공정을 의미한다. 이러한 반도체 패키징 공정 후 산출되는 최종 제품은 주로 PC/휴대폰/웨어러블 기기<br>등의 IT 제품이다. |

| 패키징 공정의 개요 |  |  | 패키징 공정은 반도체의 모듈, 기판, 칩을 순서대로 쌓는 공정을 의미하며, 반도체 모듈은 여러 개의 전자부품을 고정하고 동작시키는 판이다. 반도체 기판은 반도체 칩을 실제로 장착하는 용기로 반도체 칩이 모듈과 잘 연결될 수 있도록 해주는 필수 중간 재료이다. 반도체가<br>동작하기 위해서는 모듈, 기판, 칩의 연결과정이 필수적이며 최근 반도체의 전방산업이 다양해지면서 이에 맞는 다양한 패키징 기술이 필요해졌다. 반도체의 용도, 성능에 따른 맞춤형 패키징 기술이 필요하기 때문에 패키징 업체의 경우 다양한 기술을 보유하고 있는 것이<br>가장 주요한 경쟁력으로 꼽힌다. 따라서 반도체 모듈과 반도체 기판은 주로 고객사 맞춤형으로 공급되어 한 번 계약이 성사되면 거래관계가 장기적으로 유지된다는 특징이 있다. |

| DDR5 세대 전환으로 반도체<br>부품기업 수혜 |  | DRAM 소비자들은 고성능의 메모리칩을 선호하기 때문에 과거 DDR Cycle을 보면 기술력 향상된 DRAM이 출시되면 속도가 빠른 DRAM 수요가 증가함에따라 새롭게 출시된<br>DRAM으로 세대가 전환되었다. 전환기마다 반도체 기판 업체의 매출과 영업이익이 증가<br>했던 것으로 보이며 22F DDR5 전환기가 도래하여 DRAM 향 반도체 부품인 DRAM을 장착하는 기판 모듈 PCB 와 기판과 DRAM을 연결하는 BOC의 수요가 증가해 관련 업계의<br>매출과 영업이익이 상승할 전망이다. DDR은 DRAM으로 불리는 메모리 반도체이며 주로<br>데이터센터와 슈퍼컴퓨터에 사용된다. DDR5는 DDR4 대비 속도 2배 증가한 동시에 전력소모량은 20% 감소했다. 속도를 높이는 동시에 전력소모량을 최소화하는 것이 경쟁력인 산업 특성상, DDR5의 출하량이 증가하여 DRAM 시장 내 침투율은 22F 8%에서 25F<br>77%로 증가해 세대 전환이 가속화될 전망이다. |  |  |  |
