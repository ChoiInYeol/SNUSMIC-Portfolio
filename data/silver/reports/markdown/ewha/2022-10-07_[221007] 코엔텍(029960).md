| 폐기물 처리 산업 개요 |  |  |  | 폐기물관리법에 따르면 폐기물은 사람의 생활이나 사업활동에서 필요하지 않게 된 물질을<br>말한다. 폐기물은 발생주체에 따라 생활폐기물과 사업장 폐기물로 나뉘어진다. 생활폐기물은 가정에서 발생되는 폐기물을 말하며, 지방자치단체가 주도하여 공공 매립 시설과 소각<br>시설을 설치하고 이를 처리업체에 위탁하여 운영한다. 사업장폐기물은 공장, 건설현장 등<br>사업장에서 발생되는 폐기물을 말하며, 발생특성 및 유해성에 따라 사업장 일반폐기물, 건설폐기물, 지정폐기물로 세분화된다. 사업장폐기물의 경우 배출업체와 민간 처리업체가 통상 1년 단위의 위·수탁계약을 체결하고, 민간 처리업체가 배출업체를 대행해 폐기물 처리<br>전과정을 관리한다. |  |  |

| 폐기물 처리 산업<br>Value Chain |  |  |  | 폐기물 처리 산업 Value Chain은 일상 및 사업장에서 폐기물 배출 → 수집·운반 → 소각·매립 → 폐기물 에너지화로 구성된다. 국내 폐기물관리법에 따라 폐기물 배출업체는 보관용량, 처리실적, 처리기술 등을 고려하여 폐기물 처리업체를 선정해 위탁해야 한다. 현행법은<br>수집 및 운반업체와 처리업체 대비 배출업체에게 폐기물 처리에 대한 더 큰 책임을 부과하고 있다. 이로 인해 배출업체들이 전문성을 갖춘 대형 처리업체를 선호하는 경향이 강해지고 있다. 폐기물 에너지화는 폐기물을 재활용하여 재생에너지로 변화시키는 것으로, 대표적으로 스팀이 있다. 스팀은 폐기물 소각 시 발생되는 폐열을 활용해 생산된 것으로, 산업 활동 에너지원으로 이용되고 있다. 환경규제 강화에 따라 온실가스를 감축할 수 있는 폐기물<br>에너지화의 중요성이 커지고 있는 추세이다. |  |  |
