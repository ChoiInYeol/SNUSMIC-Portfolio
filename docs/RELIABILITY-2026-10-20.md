# 검토·체결·보관·성능 후속 작업

사용자가 운영 배포와 메타데이터 연결(1·2)을 정상 확인한 뒤 요청한 3~6 및 텔레그램 추가 작업이다.
브랜치 `feat/review-reliability-performance`에서 구현한다.

- **추출값 검토**: `/developers/review`, 실제 파싱/QA·정합 이슈 579건. 원문 전사·PDF 링크·필드별
  값 일치 후보를 표시하고 검토자/사유/근거를 갖춘 제안을 내보낸다. Silver 원자 교정·동일 파일 잠금·
  변경 이력·원문/기존값/기존교정의 낙관적 잠금. 공개 쓰기 API 없음. [사용법](RESEARCH-REVIEW.md).
- **체결 가정**: 시가 진입과 장 시작 스케일인에서 ATR을 읽는 9지점을 전일까지로 제한했다.
  장 마감 후 추적 스탑은 당일 ATR을 계속 쓴다. 시가 결측 전진 신호는 unavailable로 남긴다.
  튜닝 캐시 fingerprint를 갱신하고 SPO 워크포워드·Optuna 120회 및 전체 백테스트를 다시 실행했다.
  헤드라인은 `W_allweather_chandelier` 유지. API·통계·health·계보도 재생성했다.
  전체 금융 모델·장중 체결을 모두 검증했다는 주장은 아니다.
- **Bronze 보관**: 실제 2,776파일·4.49GB의 독립 경로 백업과 빈 경로 전체 복원을 검증했다.
  체크섬, 중복 제거, 전체/증분 최신 복구, 경로·기존 원본 보호. 선택적 S3 업로드를 refresh에 연결했다.
  같은 디스크의 로컬 백업은 디스크 고장에 대비한 외부 보관과 다르다. [복구·외부 설정](BRONZE-BACKUP.md).
- **전송량**: 홈은 화면에서 이미 제외하던 archive 시대 행을 서버에서 제외하고 필드명을 한 번만 전송한다.
  현대 보고서 1,026건은 모든 필드의 round-trip 동등성을 검사한다.
  JSON UTF-8 2,410,789→836,216 bytes (**65.3% 감소**); 네트워크 압축 후 크기나 전체 HTML 크기 비교는 아니다.
  커맨드 팔레트는 전체 report-model 동적 import 대신 빌드 시 생성한 507,498-byte 검색 색인을 첫 사용에만 가져온다.
  검토 목록은 504,983 bytes이며 전사 근거는 보고서 선택 시 개별 로드한다.
- **계보 탐색**: 인접·상류·하류 범위와 ETL 강조, SVG 반영. 이전 JSON과 구조 비교.
  같은 단일 메타데이터 모델을 사용하며 생성 시각·행 수를 DDL로 오인하지 않는다.
- **모의 포트폴리오**: 기록 시작 시 현금 1억원, 이후 공표 비중을 다음 가용 종가에서 추종한다.
  과거 백테스트 수익을 전진 수익으로 소급하지 않는다. 첫 기록일 KST 2026-10-20, 초기 수익률 0%.
  보유/목표 비중을 구분한다. 일별 평가·종목별 시세일·FX·비용과 매일 20:00 KST Telegram 예약.
  [계산과 봇 설정](PORTFOLIO.md). 봇 Secrets 미등록으로 실제 수신은 아직 검증하지 못했다.

UI는 기존 Button/Input/Sheet/Table/Alert/Empty/Skeleton/ToggleGroup을 재사용했다.
공식 Field와 의존 Label/Separator를 설치했으며 Windows CLI의 잘못된 `cn` import/패키지는 제거했다.
새 UI 라이브러리·TanStack 의존성·커스텀 primitive는 추가하지 않았다.
